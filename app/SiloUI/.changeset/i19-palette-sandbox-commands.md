The command palette can now open a sandbox's page and its Checkpoints tab, fork, export or delete a sandbox, and create a new sandbox. "Open dev in {editor}…" asks for a folder first, like the editor buttons, and Fork and Delete open the same popovers as the sandbox page. Sandboxes with the same name on different computers no longer share one palette entry when choosing with the keyboard.
