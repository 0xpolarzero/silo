Settings → Computers no longer lists ChatGPT for Linux for every computer. Silo still downloads it in the background; a **Computer use components** section now appears only when a computer's download fails or its status cannot be read, with **Retry** or **Refresh**. A new switch, **Allow agents to use the computer without asking in new sandboxes**, sets the starting choice for sandboxes you create or import (off by default).
