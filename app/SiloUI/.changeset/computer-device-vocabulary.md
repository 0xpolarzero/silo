Silo now calls the environments agents use "computers" and the Macs and Linux machines running Silo "devices", and remote management is now "Connections". SSH-only computer entries are no longer offered, and any saved ones are dropped. Saved data is converted automatically on first launch. Connected devices must run the same Silo version, and when they do not, the message names the device to update. Exports from earlier versions cannot be imported.
