System notifications now arrive as soon as something happens, and only while Silo is in the background: while you are using Silo, results appear in the app instead. Each notification names the sandbox, opens it when clicked, and replaces the older one for the same event. Silo no longer notifies you about a start, stop, or restart you asked for. Notifications are now grouped as Failures, Unexpected sandbox changes, and Long tasks finished, so work that took more than a few seconds tells you when it is done even if you have switched to another app. Failed pushes, GitHub changes, port changes, checkpoints, and log exports now reach you too.
