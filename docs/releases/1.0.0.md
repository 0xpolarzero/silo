# Silo 1.0.0

### Major Changes

- 38f096a: Require one `silo` account for terminals, SSH, editors, files, and the Linux desktop. Older VMs require explicit migration or recreation instead of falling back to root. Before starting an older VM, close Silo and follow the [migration instructions](https://github.com/0xpolarzero/silo/blob/v1.0.0/docs/SiloUI-WORKING-ACCOUNT-MIGRATION.md), or recreate the VM. New VMs already use this account.

### Minor Changes

- 38f096a: Install Luda's desktop-control tools and skill for all supported agents when adding the Linux desktop, including agents installed later. Add setup and repair actions for existing desktops.
