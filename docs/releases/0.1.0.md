First versioned Silo release for Apple Silicon macOS and Linux ARM64/x86-64.

- Create, start, stop and delete local sandboxes with bundled runtime and guest tools.
- Configure GitHub repository access, Git identity and secrets per sandbox.
- Back up and restore sandboxes, with recovery for interrupted operations.
- Check for signed updates in General settings and install when ready.

macOS requires version 14 or newer. This build is ad-hoc signed, not notarized;
first launch may require Open Anyway in Privacy & Security. Linux packages target
Ubuntu 24.04-compatible systems. Local Linux sandboxes require KVM access.
AppImage supports in-app updates; Debian installations use downloaded packages.

Existing VM names and disk sizes cannot be changed. Remote-machine management
is not included. Updating Silo preserves existing sandbox disks and settings.
