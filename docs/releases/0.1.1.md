First published Silo desktop release, with signed updates from the local 0.1.0 build.

- Download and install signed Silo updates from General settings.
- Keep settings, credentials, sandbox disks and backups when upgrading.
- Stop running sandboxes only after confirmation and restart them after updating.
- Retry interrupted downloads; reject damaged updates before installation.
- Install Linux packages without replacing system Git or other host commands.

macOS requires Apple Silicon and macOS 14 or newer. The app is ad-hoc signed,
not notarized; first launch may require Open Anyway in Privacy & Security.
The VM launcher accepts only the exact bundled VM engine and Apple system
libraries. This blocks substituted engine libraries; it does not authenticate
a completely replaced copy of the ad-hoc-signed application.
Linux packages target Ubuntu 24.04-compatible systems. Local Linux sandboxes
require KVM access. AppImage supports in-app updates; Debian installations use
the downloaded package through the package manager.

Existing VM names and disk sizes cannot be changed. Remote-machine management
is not included. Existing sandbox contents are preserved by app updates.
