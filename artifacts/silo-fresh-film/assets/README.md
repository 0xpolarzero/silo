# Original Codex computer-use cursor

`codex-agent-cursor.png` is the unchanged official cursor artwork extracted from
the installed Codex app (bundle `com.openai.codex`, version 26.924.22138,
build 11645). The source is the embedded `Ci` PNG, exported as `z`, in
`webview/assets/options-menu-view-3b453ae3aeba.js` inside `app.asar`.

Dimensions: 46×48 pixels; intended rendered size: 23×24 CSS pixels.
SHA-256: `c575bc277bab1b09518433aa465be98a8c04b305fe78ed674bf016bfa350e491`.

The browser-agent-cursor wrapper uses a 24×24 box with a 12,12 center,
inner translation of 12,−2.5, a 44-degree image rotation and a compensating
−44-degree wrapper rotation. The blue glow is #339cff, with 6px at 90% and
15px at 48%. Film trajectories and press timing must be authored independently.

This supplied product asset contains no prior film composition or animation.
